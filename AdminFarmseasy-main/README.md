# Admin Dashboard

This is an **Admin Dashboard** project with a full-stack setup, including a backend and frontend. The following instructions will help you set up and run the project locally.

## Table of Contents
- [Backend Setup](#backend-setup)
- [Frontend Setup](#frontend-setup)
- [Login Credentials](#login-credentials)

## Backend Setup

1. **Install dependencies**:

bash-

npm i 

2. **Create a .env file in the backend root directory with the following content**:

PORT=5000

JWT_SECRET=myjwtsecret123!

DB_USER=FARMSEASY

DB_HOST=farmseasy.cp0q8uuqk8by.ap-south-1.rds.amazonaws.com

DB_NAME=postgres

DB_PASSWORD=9096465405

DB_PORT=5432

3. **Run the server**:

nodemon server.js

or 

npm start

## Frontend Setup

1. **Install dependencies**:

npm install

2. **Run the frontend**:

npm run dev
